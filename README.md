# 월급계산소 v0.8

## 이번 버전 핵심
- MONEY MAP 입력값을 홈·계산기·자산·목표·시뮬레이션에 연결
- 계산기 허브를 실제 작동하는 무료 계산기 3종으로 교체
  - 1억 만들기
  - 자동차 구매 부담
  - 주택대출 월 상환액
- 홈에 월급 기반 빠른 의사결정 영역 추가
- 내 자산 페이지에서 총자산·총부채 직접 수정 및 자동 저장
- 미래 시뮬레이션에 빠른 프리셋, 변경 전/후 예상자산, 목표 단축기간 추가
- 방문·클릭 테스트 분석에서 CSV 내보내기/초기화 추가
- 아직 실제 서비스하지 않는 로그인/PRO 노출을 줄이고 현재 사용 가능한 기능을 전면 배치

## 실행
index.html을 브라우저에서 열면 됩니다.

## 데이터 저장
현재 입력값과 테스트 분석값은 서버가 아니라 브라우저 localStorage에만 저장됩니다.

2. GA4 Measurement ID 연결
3. 개인정보처리방침/이용안내 페이지 추가
4. 서버 로그인이 필요해지는 시점에 인증/DB 연결
